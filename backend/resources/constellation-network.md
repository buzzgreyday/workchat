## Role
Freelance Software Developer, Constellation Network — US, remote
**January 2025 - May 2025**

## What I did
- Delivered a development kit (SDK) providing encryption, digital signing, cryptographic hashing, and transaction methods - backend/library-style software development.
- Extended ecosystem range by adding Python language support, growing the potential developer base.

## Status
Live and publicly available. The SDK is published on PyPI as **`pypergraph-dag`** (`pip install pypergraph-dag`), with source on GitHub at https://github.com/buzzgreyday/pypergraph under the MIT license. It provides secure wallet functionality in Python plus wrappers for the Constellation Network APIs, inspired by the TypeScript library DAG4.js. Anyone can install and use it today — alongside this chat application, it is the publicly usable code Michael has shipped.

## Context
This contract followed directly from his "Blockchain Wallet Modification" project, which added hardware wallet support and caught Constellation Network's attention.
