## Technologies
TypeScript, GitHub, Constellation Network, Ledger Hardware Wallet

## What it does
- Added support for transactions using the most popular hardware wallet (Ledger).
- The work drew enough attention to directly lead to the freelance contract described in "Freelance Software Developer @ Constellation Network".

## Status
Public but unofficial. The source is open and publicly readable at
https://github.com/buzzgreyday/stargazer-wallet-ledger (TypeScript, MIT licensed) — the Stargazer Wallet Chrome extension with Tessellation v2 support for the Ledger hardware wallet. It is a community modification rather than an official Constellation Network product, and it was never shipped as part of the official wallet. Describe it as public open-source work anyone can inspect, not as an official release or a maintained live service.
